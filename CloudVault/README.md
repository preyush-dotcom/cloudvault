# CloudVault

A responsive, polished static cloud-storage dashboard demo.

## Features
- Upload files into browser IndexedDB storage
- Download uploaded files
- Image, PDF, and text preview
- Search and sort
- Create folders
- Star files
- Mark files as shared (demo UI)
- Trash, restore, and permanently delete
- Storage usage indicator (500 MB demo quota)
- Grid/list view and light/dark theme
- Responsive sidebar and mobile layout

## Deploy to GitHub Pages
1. Create a GitHub repository named `CloudVault`.
2. Upload `index.html`, `style.css`, `app.js`, and this README.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to provide your website URL.

## Important
This is a frontend demo. Uploaded files are stored in the browser on the device where they are uploaded. It does not yet include real cloud storage, authentication, cross-device sync, or genuine public share links. Those features require a backend/cloud service integration.
